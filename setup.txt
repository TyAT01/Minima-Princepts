Aurelia / Princess AI — Step-by-step setup
=========================================

This repository is a Python package that runs the runtime via `princess_ai.main`.
It expects either a llama.cpp server (OpenAI-compatible) or Ollama.

1) Create and activate a virtual environment
-------------------------------------------
1.1. Create the venv (from the repo root):

    python -m venv .venv

1.2. Activate it:

    # macOS/Linux
    source .venv/bin/activate

    # Windows (PowerShell)
    .venv\Scripts\Activate.ps1

2) Install Python dependencies
------------------------------
2.1. Install the base package (required):

    pip install -e .

2.2. Optional extras (install only what you need):

    # API server (FastAPI + Uvicorn)
    pip install -e .[api]

    # Voice stack (Discord + TTS + Vosk)
    pip install -e .[voice]

    # Memory retrieval (FAISS + NumPy)
    pip install -e .[memory]

3) Start your LLM backend
-------------------------
You said you will run `llama serve` with Llama 3.1 Instruct. The runtime connects
through OpenAI-compatible llama.cpp server endpoints at /v1/chat/completions.

3.1. Example llama.cpp server command (adjust model path to your GGUF file):

    llama-server --model /path/to/llama-3.1-instruct.gguf --port 8080

4) Configure the runtime to use llama.cpp
-----------------------------------------
By default, the runtime uses Ollama. To use llama.cpp server, set these env vars:

    export PRINCESS_ENGINE=llama_cpp_server
    export PRINCESS_LLAMA_CPP_URL=http://127.0.0.1:8080
    export PRINCESS_LLAMA_CPP_MODEL=llama-3.1-instruct

Notes:
- PRINCESS_LLAMA_CPP_MODEL is optional; it will be sent as the `model` field when
  provided.
- If you *do* want Ollama instead, omit PRINCESS_ENGINE and use:

    export PRINCESS_OLLAMA_URL=http://127.0.0.1:11434
    export PRINCESS_OLLAMA_MODEL=llama3.1:8b-instruct-q4_K_M

5) Start the Aurelia runtime
----------------------------
Run the main runtime loop:

    python -m princess_ai.main

You should see a line like:

    Selected profile: <profile-name>

6) (Optional) API / WebUI integration notes
-------------------------------------------
This repo includes a FastAPI control surface in `princess_ai.api.server`, but it
does not ship a standalone GUI. If your AI GUI expects a backend, wire it to the
API endpoints exposed by `create_app(...)` and run it with Uvicorn, for example:

    uvicorn princess_ai.api.server:create_app --factory --host 0.0.0.0 --port 8000

You will need to supply the required objects (session manager, memory store,
control hub) in your own entrypoint if you want the API to reflect the running
runtime session.

7) Quick verification checklist
-------------------------------
- ✅ Virtual environment created and activated.
- ✅ Dependencies installed (base + any extras).
- ✅ llama.cpp server running and reachable at PRINCESS_LLAMA_CPP_URL.
- ✅ PRINCESS_ENGINE set to `llama_cpp_server`.
- ✅ Runtime starts with `python -m princess_ai.main`.
